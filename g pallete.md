# Indigo Palette Notes

This file captures the current visual direction for Prompt Paul.

## Core Idea

- Use a monochrome indigo palette
- Keep shadows hard and offset
- Avoid soft, blurry, or rainbow-heavy effects
- Make active states feel technical and precise

## Palette

- Primary indigo: `oklch(0.5066 0.2501 271.8903)`
- Deep indigo: `oklch(0.4486 0.2266 271.5512)`
- Bright indigo: `oklch(0.468 0.2721 279.6007)`
- Dark background: `oklch(0 0.151 268.343)`
- Light background: `oklch(0.98 0 0)`
- White: `oklch(1 0 0)`

## Visual Rules

- Use 1px borders
- Use hard shadows like `4px 4px 0px 0px`
- Increase shadow offset on hover
- Keep corners sharp or only slightly rounded
- Use gradients sparingly, mostly for headers and active states

## Motion

- Prefer short, technical transitions
- Use linear motion for loading bars
- Keep processing states obvious

## Typography

- Use mono for UI controls and labels
- Use serif only when a contrast face is helpful

## Notes

This is a working design reference, not a final brand system.
