# Humanizer Skill

## Purpose

Rewrite text so it sounds natural while keeping the original meaning.

## Guidelines

1. Vary sentence length and structure.
2. Use contractions when they sound natural.
3. Remove stiff, repetitive, or overly formal phrasing.
4. Keep the meaning intact.
5. Avoid over-formatting unless the source text needs it.
6. Add a little personality only when it fits the tone.

## Example

**Input:** The implementation of this strategy will require significant resources. Furthermore, stakeholders must be consulted throughout the process.

**Output:** This strategy is going to take real resources, and we need to keep stakeholders in the loop from the start.

## Output Format

Return only the humanized text without explaining the changes made.
