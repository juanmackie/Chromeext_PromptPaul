Agent Skills

Capability expand_more

Manage skills that provide specialized AI capabilities. Skills are loaded on demand and can be invoked via slash commands.

help_outline How to Use Skills

Slash Commands

  • /skills - List all available skills
  • /skill <name> [input] - Invoke any skill (canonical method)
  • /<skill-name> - Quick command for user-invocable skills

Examples

  • /skill humanizer Rewrite this text...
  • /humanizer Make this sound more natural...
  • use humanizer skill and rewrite this paragraph (natural language)

Skill Metadata Fields

command-tool Tool name to invoke when command-dispatch is "tool"

Web Search Grounding

Capability

Enable the sidebar Web toggle to let the LLM search the web before answering. Grounding results are returned as source-cited reference material. Choose a provider below: Exa needs no API key (free default) and falls back to Parallel when it returns nothing, or Brave Search API returns broader results but requires a key.

Exa limits: the keyless Exa free tier is rate limited. Adding an optional Exa API key below lifts those limits. For broader results, select Brave and add an API key.

Privacy: When enabled, a model-generated search query may derive from your prompt, conversation, selected text, page content, or media context and is sent to the selected provider (Brave, or Exa). With Exa, a web-search query is sent to Exa, falling back to Parallel when Exa returns nothing. The extension does not send the full conversation unless it is represented in that query. Your Brave or Exa key, when used, is stored in Chrome storage and never included in LLM request payloads, logs, or analytics.

Exa is keyless and free; when it returns nothing, the query falls back to Parallel.

Current-Page Actions

Capability

Turn on Act in the side panel to let Prompt Paul inspect and operate semantic controls on the current tab. Page text is treated as untrusted data. The first release is DOM-only: it does not control other tabs, run JavaScript, read cookies or storage, or operate passwords, one-time codes, payment fields, or security controls.

When Act is enabled, the bounded page snapshot is sent to your configured LLM endpoint. Ordinary mutations ask for approval. Trusted mode is optional and still cannot bypass hard safety blocks.

Default: off. Submits, sends, deletes, purchases, navigation, account/security changes, and credential fields remain confirmation-gated or blocked.
