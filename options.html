Agent Skills

expand_more

Manage skills that provide specialized AI capabilities. Skills are loaded on demand and can be invoked via slash commands.

help_outline How to Use Skills

Slash Commands

  • /skills - List all available skills
  • /skill <name> [input] - Invoke any skill (canonical method)
  • /<skill-name> - Quick command for user-invocable skills

Examples

  • /skill humanizer Rewrite this text...
  • /humanizer Make this sound more natural...
  • use humanizer skill and rewrite this paragraph (natural language)

Skill Metadata Fields

Field Description
user-invocable Creates a shortcut command /skillname when true (default: true)
disable-model-invocation Hides skill from AI suggestions but keeps it explicitly invocable
command-dispatch Set to "tool" for deterministic execution bypassing the AI model
command-tool Tool name to invoke when command-dispatch is "tool"
metadata OpenClaw-compatible JSON metadata (e.g., requires, install)
